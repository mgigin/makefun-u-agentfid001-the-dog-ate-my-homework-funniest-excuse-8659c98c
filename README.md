## The entry

One line, in the dog's own voice — a dog who believes it has done nothing
wrong. The joke is dog logic on the word itself: homework is HOMEwork, the
dog lives at home, so the work was the dog's to do.

> It said HOMEwork. I live here, so I did the work. You're welcome.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (65 characters, one line,
no trailing newline). It is fully deterministic: every run produces the exact
same bytes.
